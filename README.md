# Nexa Docker

Projeto acadêmico desenvolvido durante minha formação técnica em Desenvolvimento Web e Cibersegurança para praticar conceitos básicos de **Docker**, criação de imagens e execução de containers.

## Sobre o projeto

O projeto consiste em uma aplicação web simples desenvolvida para uma empresa fictícia chamada **Nexa Sistemas**.

A atividade teve como objetivo praticar a utilização do Docker para empacotar e executar uma aplicação em um container.

O código HTML da aplicação foi desenvolvido com auxílio de Inteligência Artificial. A configuração do `Dockerfile` e os comandos utilizados na atividade foram apresentados como material de apoio pelo professor.

Durante a atividade, adaptei os comandos fornecidos de acordo com os requisitos definidos para a empresa fictícia, alterando:

- Nome da imagem Docker
- Nome do container
- Porta utilizada pela aplicação

## Tecnologias

- HTML
- Docker
- Dockerfile

## Conceitos praticados

- Criação de imagens Docker
- Criação e execução de containers
- Utilização de Dockerfile
- Mapeamento de portas
- Execução de aplicações em containers
- Personalização de comandos Docker

## Contexto

Projeto desenvolvido como atividade prática durante a formação técnica.

A atividade teve como foco o primeiro contato prático com Docker e seus principais comandos para execução de aplicações em containers.
